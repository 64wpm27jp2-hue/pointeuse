# 🕒 Pointeuse Apprenti

Application web de pointage moderne permettant aux apprentis et salariés de suivre leur temps de travail.

## Fonctionnalités

### 📌 Pointage
- Heure d'entrée
- Heure de sortie
- Calcul automatique du temps travaillé
- Enregistrement des journées

### 📜 Historique
- Liste des journées travaillées
- Consultation des heures passées
- Suppression d'un pointage

### 📊 Récapitulatif
- Total des heures du mois
- Heures normales
- Heures complémentaires (35h à 39h)
- Heures supplémentaires (au-delà de 39h)
- Temps restant avant les limites

### ⚙️ Réglages
- Limite journalière personnalisable
- Limite mensuelle personnalisable
- Contrat hebdomadaire configurable
- Sauvegarde automatique des paramètres

## Design

- Interface sombre moderne
- Optimisée mobile et ordinateur
- Navigation par onglets
- Stockage local des données

## Calcul des heures

- 0 à 35h : Heures normales
- 35h à 39h : Heures complémentaires
- Plus de 39h : Heures supplémentaires

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage

## Installation

1. Télécharger le projet
2. Ouvrir le fichier `index.html`
3. Commencer à pointer
